Tanya jawab

Apakah HERITG mengunggah silsilah keluarga saya?

Tidak. Data keluarga disimpan di penyimpanan lokal aplikasi. Hamanto Studio tidak mengoperasikan sistem akun atau basis data keluarga daring untuk aplikasi saat ini.

Bisakah aplikasi digunakan tanpa internet?

Ya. Fitur inti silsilah keluarga, impor, dan ekspor bekerja tanpa koneksi jaringan.

Apakah setiap ekspor dienkripsi?

Setiap cadangan .heritg saat ini menggunakan amplop terenkripsi dengan kata sandi opsional. Ekspor GEDCOM, PNG, dan SVG tetap berupa berkas yang dapat dibaca.

Bagaimana cara memverifikasi klaim privasi?

Periksa kode sumber, kebijakan privasi, daftar pemrosesan data, kebijakan analitik, dan proses keamanan yang terbuka untuk umum.

Platform apa yang didukung?

HERITG tersedia untuk iOS, Android, dan web. Ketiganya menggunakan format cadangan .heritg terenkripsi yang sama.
