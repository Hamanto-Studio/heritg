Tanya jawab

Apakah HERITG mengunggah silsilah keluarga saya?

Tidak. Data keluarga disimpan dalam wadah lokal aplikasi. Hamanto Studio tidak mengoperasikan sistem akun atau basis data keluarga daring untuk aplikasi saat ini.

Bisakah aplikasi digunakan tanpa internet?

Ya. Fitur inti silsilah keluarga, impor, dan ekspor bekerja tanpa koneksi jaringan.

Apakah setiap ekspor dienkripsi?

Tidak. Perlindungan kata sandi tersedia untuk cadangan .heritg. Ekspor GEDCOM, PNG, dan SVG tidak dienkripsi oleh opsi ini.

Bagaimana cara memverifikasi klaim privasi?

Periksa kode sumber, kebijakan privasi, daftar pemrosesan data, kebijakan analitik, dan proses keamanan yang terbuka untuk umum.

Platform apa yang didukung?

Aplikasi iOS sedang dikembangkan aktif. Android direncanakan. Tidak ada aplikasi web atau basis data keluarga daring.
