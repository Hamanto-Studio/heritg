FAQs

Does HERITG upload my family tree?

No. Family data is stored in the local app container. Hamanto Studio does not operate an account system or hosted family database for the current app.

Can I use the app without the internet?

Yes. Core family-tree features, imports, and exports work without a network connection.

Is every export encrypted?

No. Password protection is available for .heritg backups. GEDCOM, PNG, and SVG exports are not encrypted by this option.

How can I verify the privacy claims?

Review the public source code, privacy policy, data processing register, analytics policy, and security process linked on this page.

What platforms are supported?

The iOS app is in active development. Android is planned. There is no hosted web app or family database.
