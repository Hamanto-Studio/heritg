Kebijakan Privasi HERITG

Berlaku mulai 12 September 2026

HERITG dikembangkan oleh Hamanto Studio untuk membantu orang menyimpan silsilah keluarga tanpa membuat akun atau mengirimkan informasi keluarga kepada Hamanto Studio.

Tidak perlu mendaftar. Data keluarga disimpan secara lokal. Fungsi inti bekerja secara luring. Layanan akun, berbagi terenkripsi, dan Family+ bersifat opsional dan menggunakan backend. Statistik penggunaan Web nonaktif secara bawaan dan memerlukan persetujuan. Tidak ada SDK iklan atau analitik pihak ketiga.

Data keluarga

Nama, hubungan, tanggal, foto, catatan, dan arsip genealogi yang diimpor disimpan dalam wadah lokal aplikasi. Berbagi dan sinkronisasi opsional mengunggah salinan terenkripsi, bukan data keluarga dalam teks biasa.

Impor dan ekspor

Impor diproses di perangkat. Pengguna memilih sendiri tujuan berbagi ekspor. Setelah ekspor meninggalkan HERITG, aplikasi, layanan, dan penerima yang dipilih akan mengendalikan penanganannya.

Analitik dan diagnostik

Jika pengumpulan diaktifkan, pengguna Web dapat memilih statistik penggunaan opsional di Setelan dan menonaktifkannya tanpa kehilangan fitur. Do Not Track dan Global Privacy Control tetap menonaktifkan pengumpulan. Persetujuan berlaku paling lama 180 hari. Tahap dan hasil alur memakai ID percobaan acak berumur pendek, bukan isi keluarga, identitas akun, URL, kata sandi, atau rekaman layar.

Catatan dikecualikan dari laporan setelah 30 hari di penyimpanan pribadi Jakarta; penghapusan dan salinan pemulihan dapat memerlukan waktu lebih lama. Percobaan checkout dan penjelajahan Family+ dapat disimpan hingga 24 jam untuk kembali dari pembayaran pada tab yang sama. Statistik ini tidak terenkripsi menyeluruh terhadap Heritg. Operator berwenang dapat merangkum status tagihan terverifikasi secara terpisah tanpa menghubungkannya ke identitas browser. Lihat kebijakan data, retensi, dan peluncuran lengkap. Pelaporan kerusakan pihak ketiga, Firebase Analytics, dan Google Analytics tidak digunakan.

Hosting web dan pembayaran

Cloudflare menyediakan hosting web dan meneruskan permintaan API ke Google Cloud di Jakarta. Penyedia ini memproses metadata permintaan dan muatan terenkripsi untuk menjalankan layanan. Respons API tidak disimpan dalam cache; log aplikasi tidak memuat konten pribadi atau kredensial. DOKU memproses pembayaran Family+ sekali bayar. HERITG menyimpan paket, nominal, referensi tagihan, status terverifikasi, dan masa akses, bukan kredensial bank atau data keluarga dalam catatan pembayaran. Tidak ada penagihan otomatis.

App Store

Apple memproses unduhan, pembayaran, dan informasi platform terkait sesuai kebijakan privasi Apple. Hamanto Studio dapat menerima laporan App Store yang bersifat agregat.

Iklan dan pelacakan

HERITG tidak menjual data keluarga dan tidak menggunakan SDK iklan, sidik jari perangkat, atau pelacakan lintas aplikasi.

Kontak

Hubungi Hamanto Studio melalui Telegram. Jangan sertakan data keluarga, kunci privat, atau kredensial dalam pesan pertama.
